# Documentation

## Mandatory requirements

Maintain root README with architecture, endpoint registration, cookie flow, env setup, exact human commands, risks and deferred work. Keep docs scoped to the frontend foundation and use fictional examples. Record incomplete verification and backend contract discrepancies.

## Prohibited patterns

No unrelated pages, copied vendor documentation, real identities/credentials or claims that tests ran.

## Good example

README explains that a login challenge is not a session and that cookies are reissued for the admin host.

## Review criteria

Check source parity, setup reproducibility, release blockers, security review and deferred features.
